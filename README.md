# UniTools — เครื่องมือสำหรับงานมหาวิทยาลัย

เว็บไซต์ภาษาไทยแบบ static ใช้ HTML, CSS และ JavaScript โดยตรง ไม่ต้องติดตั้ง npm หรือ build รองรับมือถือและโหมดมืดตามอุปกรณ์

## วิธีเปิด

เปิด `index.html` ด้วยเบราว์เซอร์รุ่นปัจจุบันได้โดยตรง แนะนำให้เปิดผ่าน HTTP เพื่อให้การคัดลอกและการเก็บข้อมูลทำงานสม่ำเสมอ:

```sh
cd /path/to/unitools
python3 -m http.server 8765
```

แล้วเปิด <http://localhost:8765> หยุดเซิร์ฟเวอร์ด้วย Ctrl+C การคัดลอกผ่าน Clipboard API ทำงานบน HTTPS หรือ localhost; มีวิธีคัดลอกสำรองสำหรับบริบทอื่น

## วิธีเผยแพร่

อัปโหลด `index.html`, โฟลเดอร์ `assets/` และ `tools/` ทั้งโฟลเดอร์ไปยัง static hosting เช่น GitHub Pages, Cloudflare Pages หรือเว็บเซิร์ฟเวอร์มหาวิทยาลัย ตั้ง `index.html` เป็นหน้าเริ่มต้น และเปิด HTTPS ไม่ต้องมี backend หรือ secret สามารถติดตั้งใต้ subdirectory ได้เพราะลิงก์ภายในใช้ relative path

ก่อนเผยแพร่ต้องมี `tools/pdf.html` และ `tools/certificate.html` พร้อม JavaScript และ assets ที่งานอีกส่วนจัดทำไว้ หน้าแรกเชื่อมไปยังเครื่องมือทั้ง 19 หน้าแล้ว

## ไฟล์ในงานส่วนนี้

- `index.html` — รวมเครื่องมือ แบ่ง 5 หมวด พร้อมช่องค้นหา
- `assets/style.css`, `assets/common.js` — สไตล์และตัวช่วย `window.UT` ตาม shared contract
- `tools/shorten.html` และ `tools/js/shorten.js` — is.gd JSONP, ชื่อท้ายลิงก์, คัดลอก, ส่งต่อไป QR และประวัติ 20 รายการ
- `tools/qr.html` และ `tools/js/qr.js` — QR ข้อความ, Wi-Fi, PromptPay, โลโก้, PNG/SVG; qrcode-generator **1.4.4** ผ่าน jsDelivr
- `tools/wheel.html` และ `tools/js/wheel.js` — วงล้อ canvas, สุ่มด้วย crypto, เสียง, เต็มจอ และลบผู้ชนะ
- `tools/vote.html?mode=postit` — บอร์ดโพสต์อิทแบบเปิดตรง ใช้ชุดคำถามแยกจากโหวตสด
- `tools/vote.html` และ `tools/js/vote.js` — โหวตสด 5 รูปแบบ รวมบอร์ดโพสต์อิทแยกคอลัมน์ จัดเรียง/เน้น/สุ่มโน้ต ผ่าน PeerJS peer-to-peer, ชุดคำถาม JSON และผล CSV; ผู้จัดเปิดหน้าไว้เพื่อรับคำตอบ
- `tools/password.html` และ `tools/js/password.js` — สุ่มรหัสผ่าน/วลีลับด้วย Web Crypto, สร้างหลายรหัสและส่งออก CSV; จำเฉพาะตัวเลือก ไม่เก็บรหัสผ่านหรือรายชื่อ
- `tools/groups.html` และ `tools/js/groups.js` — แบ่งกลุ่ม, คัดลอก และ CSV พร้อม UTF-8 BOM
- `tools/baht-text.html` และ `tools/js/baht-text.js` — อ่านจำนวนเงิน, ปัดสตางค์แบบฐานสิบ, เลขไทย/อารบิก และตารางทดสอบ 16 กรณี
- `tools/dates.html` และ `tools/js/dates.js` — พ.ศ./ค.ศ., นับ/เพิ่มวันทำการ และรายการวันหยุดแก้ไขได้
- `tools/timer.html` และ `tools/js/timer.js` — นับถอยหลัง, stopwatch, เสียงเตือน และปุ่มลัด Space/R
- `tools/word-count.html` และ `tools/js/word-count.js` — นับคำด้วย Intl.Segmenter, อักขระ, ย่อหน้า, เวลาอ่าน และปรับข้อความ
- `tests/logic.test.js`, `tests/smoke.test.js`, `tests/check-http.sh` — การตรวจสอบ

ไม่ได้สร้างหรือแก้ไขไฟล์ PDF/เกียรติบัตรหรือ JavaScript ของสองหน้านั้น

## ข้อมูลและข้อจำกัด

ประวัติลิงก์ รายการวงล้อ และวันหยุดเก็บใน localStorage ของเบราว์เซอร์นี้ การล้างข้อมูลเว็บไซต์จะลบข้อมูลดังกล่าว ถ้าพื้นที่เก็บถูกปิด เครื่องมือยังใช้ได้แต่จะไม่จำข้อมูล

การย่อลิงก์ส่ง URL และ alias ไปยัง **is.gd** และขึ้นกับเครือข่าย/ข้อจำกัดบริการ ส่วนข้อความและภาพที่เลือกในเครื่องมืออื่นประมวลผลบนอุปกรณ์ ภาพโลโก้ไม่ถูกอัปโหลด QR และฟอนต์ Google Fonts ต้องมีอินเทอร์เน็ตเพื่อโหลดจาก CDN/Google Fonts

QR พร้อมโลโก้ใช้ error correction H อัตโนมัติ ควรสแกนทดสอบด้วยอุปกรณ์จริง โดยเฉพาะ QR ที่เปลี่ยนสีหรือมีข้อความยาว เลข PromptPay ใช้ตรวจรูปแบบเท่านั้น ไม่ได้ยืนยันเจ้าของบัญชี ต้องตรวจชื่อผู้รับในแอปธนาคารก่อนชำระ

รายการวันหยุดเริ่มต้นปี 2026–2027 มีเฉพาะวันวันที่แน่นอนและวันชดเชยที่คำนวณได้ **ไม่ได้อ้างว่าเป็นปฏิทินราชการครบถ้วน** ไม่รวมวันทางจันทรคติ วันพืชมงคล และวันหยุดพิเศษทั้งหมด วันแรงงานอาจไม่เป็นวันหยุดของมหาวิทยาลัย ให้แก้ไขตามประกาศหน่วยงาน โดยตรวจเทียบกับ [ธนาคารแห่งประเทศไทย](https://www.bot.or.th/th/financial-institutions-holiday.html) และประกาศมหาวิทยาลัย บรรทัดวันที่ผิดจะหยุดการคำนวณจนกว่าจะแก้ไข

วันที่ 24 พฤศจิกายน 2026 เป็นวันอังคาร การแสดงผลคำนวณจากวันที่จริงด้วย Intl ไม่ยึดชื่อวันจากตัวอย่างข้อความ

เสียงและ fullscreen ขึ้นกับเบราว์เซอร์ ตัวจับเวลาอิงเวลาที่ผ่านไปจริงระหว่างเปิดหน้า แต่เบราว์เซอร์อาจหน่วงเสียงเมื่อแท็บอยู่เบื้องหลังหรืออุปกรณ์พักเครื่อง ข้อความไทยที่ไม่มี Intl.Segmenter จะใช้การแบ่งคำตามช่องว่างพร้อมแจ้งข้อจำกัด ปุ่มแก้สระปรับ `ํา` / `นํ้า` และเครื่องหมายซ้ำที่พบบ่อย ไม่สามารถซ่อมข้อความเสียจาก PDF ได้ทุกแบบ

## ตรวจสอบ

```sh
node tests/logic.test.js
node tests/smoke.test.js
node tests/password.test.js
node tests/fixtures-b/check.cjs
sh tests/check-http.sh
```

- Logic tests ผ่าน: คำอ่านเงิน 21 กรณีและข้อมูลผิด, PromptPay ตัวอย่างโทรศัพท์แบบ static/ระบุจำนวนเงิน, TLV, เลขประจำตัว และ CRC16-CCITT ที่ตรวจด้วย implementation อิสระ มี self-check ใน console ของหน้า QR ด้วย
- Smoke tests ผ่าน: โหลด JavaScript ทั้ง 8 หน้าใน DOM จำลอง ทดสอบวันที่/วันหยุด, กลุ่ม/CSV BOM, จับเวลา, ปรับข้อความ, สลับวงล้อ, QR เมื่อ CDN โหลดไม่ได้ และ JSONP/ลิงก์ส่งต่อ QR
- ตรวจ `node --check` ผ่านทุกไฟล์ JS ในส่วนนี้ และตรวจว่าลิงก์/assets ภายในมีไฟล์จริง รวม PDF และเกียรติบัตร
- **ข้อจำกัดการตรวจในสภาพแวดล้อมสร้างงาน:** `python3 -m http.server 8765` ถูก sandbox ปฏิเสธการเปิดพอร์ต (`Operation not permitted`); `curl` CDN หา DNS ไม่ได้ และ localhost คืน 000 จึงยังไม่ยืนยัน HTTP 200 หรือ CDN 200 เครื่องมือควบคุม Chrome ปฏิเสธการเข้าถึง จึงยังไม่ตรวจการแสดงผล/console ในเบราว์เซอร์จริง DOM จำลองไม่ใช่การทดสอบ browser หรือการสแกน QR จริง

ให้รัน `sh tests/check-http.sh` ในสภาพแวดล้อมที่เปิดพอร์ตและออกอินเทอร์เน็ตได้ จากนั้นเปิดทั้ง 19 หน้าด้วยเบราว์เซอร์ ตรวจ Console และลองสแกน QR ก่อนใช้งานจริง

CSV ของเครื่องมือรหัสผ่านใช้ UTF-8 BOM และเติม apostrophe หน้าค่าที่เริ่มด้วยสัญลักษณ์สูตร เพื่อให้ Excel อ่านเป็นข้อความ

## เพิ่มเติม: จับฉลากรางวัล และสุ่มเรียกชื่อ

หน้าแรกรวม **19 เครื่องมือ** (หมวดสุ่ม & กิจกรรม 8 เครื่องมือ; งานเลี้ยง & อีเวนต์ 4 เครื่องมือ) รวมแข่งตอบคำถามและกดออดแข่งตอบ

- `tools/raffle.html`, `tools/js/raffle.js` — วางรายชื่อหรืออ่าน .xlsx/.csv (สองคอลัมน์แรก: ชื่อ, แผนก; ข้ามหัวตาราง ชื่อ/ชื่อ-นามสกุล/name) ตัดรายการที่ชื่อและแผนกตรงกัน พร้อมแจ้งจำนวนซ้ำ เรียงรางวัลจากเล็กไปใหญ่ด้วย ↑/↓ หรือกลับลำดับ จับทีละชิ้น/ทั้งชุดได้ แต่ละชุดเลือกคนไม่ซ้ำกัน ตัวเลือกหนึ่งคนรับครั้งเดียวเปิดเริ่มต้น
- เวทีจับฉลากรองรับเต็มจอ จอโปรเจกเตอร์ Space/F/M เสียง WebAudio และ canvas confetti ชื่อผู้ชนะเลือกด้วย `crypto.getRandomValues` และ rejection sampling **ก่อน** แอนิเมชัน 4 วินาที เริ่มบันทึกใน `UT.store` ก่อนแสดงผล รีเฟรชแล้วกลับมายืนยันผลเดิมได้ สุ่มใหม่บันทึกว่า “ไม่อยู่” และตัดคนนั้นออกตลอดงาน ข้ามบันทึกชิ้นรางวัลที่ข้าม แสดงผลและส่งออก CSV รวมสถานะ/รอยืนยันได้ ปุ่มพิมพ์มีรูปแบบสำหรับพิมพ์รายชื่อ การเริ่มใหม่ทั้งหมดต้องยืนยัน
- `tools/picker.html`, `tools/js/picker.js` — สร้าง/เลือก/เปลี่ยนชื่อ/ลบห้อง วางหรือนำเข้ารายชื่อ เก็บรอบและคะแนนแยกตามห้อง สุ่มไม่ซ้ำจนเรียกครบ ย้อนกลับด้วย U เริ่มรอบใหม่เมื่อครบ ตั้งขาด/ไม่อยู่รายคนได้ สถานะขาดรีเซ็ตตามวันที่ท้องถิ่น (ตรวจเมื่อโหลดหน้าและก่อนสุ่ม) คะแนนสะสมคงอยู่ ส่งออก CSV ได้ ปุ่มคะแนนเปิดด้วยตัวเลือก และปรากฏข้างผู้ที่เรียกแล้ว
- ทุกห้องและผลกิจกรรมเก็บเฉพาะใน localStorage ของเบราว์เซอร์นี้ การล้างข้อมูลเว็บไซต์จะลบข้อมูล ควรส่งออก CSV สำรอง ข้อมูลไม่ถูกอัปโหลด ทั้งสองหน้ารองรับ reduced motion (แสดงผลทันทีและงด confetti) พร้อม fullscreen และปุ่มลัดที่ไม่รบกวนการพิมพ์
- SheetJS ปักเวอร์ชัน **0.18.5** จาก jsDelivr เหมือนหน้าเกียรติบัตร ใช้เฉพาะ .xlsx; CSV/วางชื่อยังทำงานเมื่อ CDN โหลดไม่ได้ CSV ส่งออกใช้ UTF-8 BOM และป้องกันเซลล์เริ่มต้นเป็นสูตร Excel
- `tests/raffle.test.js` ตรวจ rejection sampling, ความสม่ำเสมอ, ไม่ซ้ำ, ลำดับรางวัล, การยืนยัน/ไม่อยู่/ข้าม/กู้ผลค้าง, รอบเรียกชื่อ, ย้อนกลับ, คะแนน, CSV และการเชื่อมต่อปุ่มหน้าเว็บ

```sh
node tests/logic.test.js
node tests/smoke.test.js
node tests/fixtures-b/check.cjs
node tests/password.test.js
node tests/vote.test.js
node tests/raffle.test.js
```

ในผลแบบทั้งชุด ใช้ปุ่ม “ไม่อยู่ · เปลี่ยนคนนี้” ใต้ชื่อเพื่อเปลี่ยนเฉพาะคนนั้น ผู้รอยืนยันคนอื่นยังคงเดิม ปุ่ม “สุ่มใหม่ · ทั้งชุดไม่อยู่” ใช้เมื่อทั้งชุดไม่อยู่ หากผู้มีสิทธิ์ไม่พอจะเก็บบันทึกไม่อยู่และผู้รอยืนยันที่เหลือไว้ ไม่ทิ้งผล

การตรวจรอบเพิ่มเติม: ทั้ง 6 ชุดคำสั่งด้านบนผ่าน รวมการกู้คืนผลก่อนยืนยันและเปลี่ยนผู้ไม่อยู่รายคนในชุด การตรวจภาพจริงยังทำไม่ได้ในสภาพแวดล้อมนี้ (browser access host unavailable และ sandbox ไม่อนุญาตเปิดพอร์ต HTTP)

- `tools/quiz.html`, `tools/js/quiz.js` — แข่งตอบคำถามผ่าน PeerJS: ชุดคำถามพร้อมภาพ นำเข้า XLSX/CSV/JSON แม่แบบ CSV คะแนนตามเวลารับจริงที่ผู้จัด สตรีก อันดับร่วม แท่นรางวัล และผล CSV รายคนรายข้อ; กลับเข้าห้องเดิมเพื่อกู้เกมหลังรีเฟรช
- `tools/buzzer.html`, `tools/js/buzzer.js` — กดออดแข่งตอบผ่าน PeerJS: ทีม ลำดับและส่วนต่างเวลารับจริง ล็อกคนตอบผิด คะแนนผู้เล่น/ทีม และ CSV; Space เปิดออด
- `assets/room.js` — `UTRoom` รหัสห้อง โฮสต์ การเชื่อมต่อซ้ำแบบ backoff สถานะ ลิงก์และ QR; แยก peer prefix ของ vote/quiz/buzz ส่วน `assets/activity.js` ใช้ร่วมกันสำหรับชื่อเล่น ล็อบบี และ UI กิจกรรมสด
- ห้องสดต้องมีอินเทอร์เน็ตและผู้จัดเปิดแท็บไว้ ผู้ร่วมเล่นใช้รหัสอุปกรณ์ใน localStorage ชื่อซ้ำจะเติมเลขท้าย ห้องแบบ quiz รับคนใหม่ระหว่างข้อ ผู้จัดกด “กลับเข้าห้องเดิม” หลังรีเฟรช; ระบบจะพยายามยึด peer ID เดิมก่อนออกโค้ดใหม่

```sh
node tests/quiz.test.js
```

- `tools/gift-exchange.html`, `tools/js/gift-exchange.js` — จับคู่แลกของขวัญเป็นวงเดียวตามข้อห้าม ลิงก์ส่วนตัวแบบ obfuscation และสลิปพับ A4; จำข้อมูลผู้จัดในเบราว์เซอร์
- `tools/checkin.html`, `tools/js/checkin.js` — ลงทะเบียนสดผ่าน UTRoom พร้อมคีออสก์ กันรหัสอุปกรณ์ซ้ำ กู้ห้อง ส่งออก CSV และส่งรายชื่อไปจับฉลาก (ผู้จัดต้องเปิดแท็บไว้)
- `tools/countdown.html`, `tools/js/countdown.js` — นับสู่ปีใหม่/เวลาที่กำหนดด้วยนาฬิกาเครื่อง เวทีเต็มจอ เสียงและพลุ รองรับ reduced motion และซ้อม 10 วินาที
- `tests/events.test.js` — ตรวจข้อจำกัดวงของขวัญ ลิงก์ ลงทะเบียนซ้ำ นำเข้าจับฉลาก และเวลานับถอยหลัง; รัน `node tests/events.test.js`
